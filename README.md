# 🚒 자랑스러운 우리들의 영웅! 소방관 임용 축하 웹페이지

소방관이 된 친구의 합격과 임용을 축하하고 응원하기 위해 제작된 인터랙티브 축하 웹페이지입니다.

## 🔗 접속 링크
- **웹사이트 주소**: `https://itroqkfwk.github.io/firefighter/`

## ✨ 주요 기능
- 🎨 **고화질 신임 소방관 축하 포스터**
- 💌 **진심을 담은 따뜻한 격려 및 응원 편지**
- 🛡️ **소방관 제1수칙(무사귀환) 및 응원 카드**
- 👏 **실시간 응원 박수 카운터 & 팡파르 효과음**
- 💬 **축하 메시지 롤링페이퍼 (실시간 작성 및 저장)**
- 🎊 **황금빛 축하 폭죽(Confetti) 애니메이션**
